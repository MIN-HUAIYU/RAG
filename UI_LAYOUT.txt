═══════════════════════════════════════════════════════════════════════════════════
                              常见问题快速诊断
═══════════════════════════════════════════════════════════════════════════════════

问题 1: 看不到 "📚 知识库管理" 标题
├─► 原因: RAG 模块未加载
├─► 检查: python test_ui.py
└─► 解决: pip install -r requirements.txt

问题 2: 看到标题但没有上传区域
├─► 原因: 浏览器缓存或代码错误
├─► 检查: 查看浏览器控制台（F12）
└─► 解决: Ctrl + F5 强制刷新

问题 3: 上传按钮是灰色的
├─► 原因: 未选择文件
├─► 检查: 是否看到 "📄 已选择: xxx.pdf"
└─► 解决: 先选择 PDF 或 TXT 文件

问题 4: 点击上传后报错
├─► 原因: 依赖包未安装或文件格式不支持
├─► 检查: 查看错误提示信息
└─► 解决:
    ├─► 确保文件是 PDF 或 TXT 格式
    ├─► 运行: pip install PyPDF2
    └─► 检查文件大小是否 < 50MB
